Comic: frames, gutters, effect lines

Frame folders

The last frame takes a one-shot confirm. Pressing Delete on a frame folder's LAST panel arms (the status line tells you the next press removes the folder); any other command disarms it; the second press deletes the folder together with its layers. Every other frame deletes on the first press — the guard exists only where Delete would take the art with it.
Dragging a shared gutter moves both panels. Borders created by dividing a page stay linked: drag one and the neighbour's edge follows as one gesture — and if the drag would squash a neighbour into a broken shape, the whole edit reverts (the status line says so). Release near a neighbour's edge to snap.
Panel numbers are reading order, not names. The badge on each frame folder recomputes from the page's geometry (top-right first in right-to-left), so moving a panel renumbers the page. Rename a folder and the name is yours — the badge keeps carrying the number.

Art bursting out of a panel

Select a layer inside a frame folder and tick Burst out of the panel in Layer Property ▸ Layer settings. That one layer draws outside the panel mask and OVER the frame's border ink — the classic overflow shot — while everything else in the folder stays clipped. The layer keeps living inside the folder (it moves, hides and locks with the panel), the frame stays fully editable, and unticking puts the art back inside. In Clip Studio this takes a stack of white-fill layers and a hand-made mask, or rasterizing the frame folder for good.
The bursting layer ignores the folder's opacity and blend. It composites as if it sat just above the frame folder, so a 50% folder dims the panel but not the burst. Want the burst dimmed too? Set the layer's own opacity.

Crop marks and margins

The bleed, trim, inner border and publisher safety margins come from the page's comic settings and are drawn over the canvas. View ▸ Crop marks and margins unticks them.

Hiding them changes nothing about the page. The sizes stay in the work settings, panel edges still snap to the same lines, and export never drew them in the first place — the switch is about what you can see while you draw, not about what the page is.
This one is remembered between sessions (guides_hidden= in ui.txt), unlike Tab and Shift+Tab, which always come back on the next launch. Hiding the guides is a way of working; hiding the palettes is a key you pressed.
A canvas made from a pixel preset has no guides. They are millimetre geometry at a dpi, so a canvas created in pixels has nothing to draw and the switch has nothing to do.
To change the paper after the work exists, use Edit ▸ Change work resolution… — not Work Settings. Work Settings re-draws the guides and moves no pixels, so retyping the paper size there leaves every page the wrong size for its own paper. The resolution dialog has a Paper picker beside the dpi: pick a preset and every page is rescaled onto it in the same pass, with the trim, bleed and inner border coming along. The dpi field decides the resolution — picking “A4 Color 350dpi” as a shape does not drag its 350 in with it. Like any whole-work resample this cannot be undone, so it asks you to save first.
The inner border and safety margins know which side of the book the page is. In a right-bound work, odd pages sit left and even pages sit right (page 1 is a left page), so the binding edge — the ノド, where margin has to be generous because the fold eats it — swaps sides page by page. The guides mirror to match, the frame folder a new page is seeded with follows, and a combined spread shows both sides' frames with the fold between them. A setup's X offset is stored once, in right-page orientation; the page's book side decides its sign. Two facing pages wearing the same offset — both gutters on one side — is exactly the mistake print rejects.

Cutting panels

What a cut does to the art is a setting, not a rule. With the Divide frame folder sub tool, Tool Property ▸ Contents of the new folder picks between Create empty folder (the default — the new half starts blank), Duplicate layer (the new half gets a copy of the folder's contents, so a panel you have already drawn keeps its drawing in both halves) and Do not change (draw the border only; no new folder, nothing moves). Cutting a drawn panel on the default setting leaves the art in the ORIGINAL half only — that is the setting talking, not a bug.
Tap a panel edge, and it runs off the page. With either divide sub tool, a click that does not turn into a drag extends the panel edge nearest the tap out past the paper — the bleed panel in one tap. If another panel of the same folder faces that edge, the edge stops flush against it instead and the gutter between the two closes. A drag still divides; only a tap extends.
Divide equally uses the gutter values above it, and needs to know which panel. Tool Property ▸ Columns/Rows ▸ Divide equally cuts the panel into the whole grid in one command, spacing it with the divide sub tool's own Gutter L/R and T/B. When the folder holds more than one panel it will not guess: select the panel with the Object tool first. Fit to side direction divides a tilted panel along its own slant rather than true vertical and horizontal.
A bent cut makes panels that cannot be cut again. Cutting along a bent or curved path leaves concave panels, and the divide tool only cuts convex ones — so plan the straight cuts first and the shaped ones last.

Borders you ink yourself

Turning a border off turns it into a ruler. Right-click a frame folder's reading-order badge ▸ Border off — outline becomes a ruler. The folder keeps its shape and still masks its contents, but lays down no ink: instead the outline joins the curve rulers, so a pen snaps to it and you ink the panel edge yourself with real pressure and brush character. Two consequences worth knowing: it switches ruler snapping ON for the whole document (a ruler you cannot snap to is not a ruler), and the border width you had is remembered, not thrown away — the same menu item inks it back at the same weight. A border ruler belongs to its frame, which is why Delete all rulers leaves it alone — see Rulers & perspective.

Balloons

There is no “fill inside frame” switch — set Fill opacity to 0. A bubble with no fill is a bubble whose fill you cannot see, so Tool Property gives you one control instead of two: drop Fill opacity to zero and the outline inks while the art behind shows straight through. The panel says so under the bar when you get there.
A screened balloon’s cell is measured in canvas pixels, not lines per inch. Tick Screened fill and the Cell bar is px. Changing the document’s resolution afterwards does not re-flow that screen — it stays the size you gave it, and you re-set it by hand. A tone layer is specified in lpi and does follow the dpi; the two are deliberately different and this is the one place it shows.
Tail type and bend apply to the whole balloon, not to one tail. There is no way to select a single tail, so setting Thought or Shout on a bubble sets every tail it has. If you have somehow given one balloon two differently-shaped tails, the panel shows the tool’s own setting rather than picking one of them to call the truth — and the next change makes them match.
Only a drawn bubble can be rotated. The rotation knob is offered on every balloon, but an ellipse and a rounded rectangle are stored axis-aligned: turning one moves nothing (an ellipse with no tail comes out of the drag identical). Draw the bubble with the Balloon tool’s pen mode if you need it tilted. This is also why turning an ellipse does not take its lettering with it — see Text & objects.
Fit to text sizes the bubble around the topmost visible lettering inside its BODY. The button is in Tool Property with the balloon selected in the Object tool. There is no stored balloon→text link in this app and Fit does not invent one — the pairing is geometry, the same way a click finds things: every visible text layer is walked bottom to top and the last hit wins. An item belongs when its centre is inside the body, or (for lettering already spilling out of a bubble too small for it, which is the whole reason to press Fit) when any of its corners is. A tail is somewhere the bubble points, not somewhere lettering goes, so an SFX sitting over the tail cannot capture the fit.
The centre stays where you put it, and the tail comes along. The bubble is resized about where it already sits rather than moved onto the text's centre — you placed it against the art. Each tail's BASE rides the boundary out with the body and its TIP does not move, because the speaker did not move; tail kinds, bends, widths, the ink style and the border width are not a fit's business. Off-centre lettering therefore grows the bubble on that side instead of sliding it. The margin is 0.75 em of the lettering's own type size, so a 9 pt bubble and a 24 pt shout get the same optical breathing room rather than the same pixel count.
A hand-drawn bubble scales UNIFORMLY and keeps its shape. One factor on both axes, measured against the drawn outline itself rather than its bounding box — so a concave bubble is honoured, every anchor's pressure survives, and it is never rounded back into an ellipse. Ellipses and rounded rects get a writing-direction clamp instead (a little taller than wide for tategaki, wider than tall for yokogaki); that clamp is deliberately not applied to a drawing, because restyling your drawing is not what you asked for.
Hidden text layers are skipped — locked ones are not. You cannot size a bubble against lettering you cannot see, so a hidden layer is not a candidate at all. A LOCKED layer still counts: the fit reads the lettering and writes only the balloon, so nothing locked is edited. With no lettering found inside the body the status bar says so and nothing moves, and a bubble that already fits is left alone. One press is one undo step.
Two balloons that overlap on one layer become one balloon — including their colour. The shared edge is erased, which is what makes a tail merge into its bubble. Where two differently coloured balloons overlap, each pixel takes the ink of whichever body or tail is nearest to it, so the two colours meet along the ridge between them. Put them on separate balloon layers if you want a hard edge instead.

Effect lines

The fastest way in is the Figure tool. The Figure tool carries the same three groups Clip Studio's does: Direct draw (line, rectangle, ellipse, polygon — inked with the active brush), Stream line and Saturated line. With a line sub tool armed, one drag places the lines: a saturated-line drag goes from the convergence point out to where the rays should reach, a stream-line drag runs along the motion (its angle and length come from the drag). Every drag makes its OWN layer — one Ctrl+Z removes it, and the layer is a normal generator afterwards: Object-tool handles and Layer ▸ Edit effect lines both adjust it. The knobs live in Tool Property (Figure and Wobble) and apply to the next drag; with a placed set selected under the Object tool the same knobs edit that set instead.
Ten sub tool rows, in two groups. Stream line holds Stream line, Dense stream, Sparse stream, Perspective stream (the runs fan into an impact point instead of sliding past) and Drip lines (short verticals hanging off the edge you drag). Saturated line holds Saturated line, Dense saturated line, Dark burst, Sea urchin flash and Solid flash. Picking a row loads its whole set of knobs; tweak any of them and no row is lit any more, the same way a modified brush preset behaves. Making your own rows — right-click ▸ duplicate, rename, save current settings — is the next piece of work and is not in yet.

What each knob does

All of these sit in Tool Property while a line sub tool is armed, and on the selected set under the Object tool. Widths and gaps are in millimetres, not pixels: a millimetre is the same size on a 600 dpi print page and on a rough draft, and a pixel is not.

Figure — what a line is.

KnobWhat it does on the page
GapHow far apart neighbouring lines sit: degrees for a burst (about 2° packed, 10° airy), millimetres for a stream. On the flashes this row says Spikes instead and counts the teeth.
BundleHow many lines sit together before a hole — the Japanese term is まとまり. The second number is how wide that hole is, counted in gaps, so 3× means a hole three gaps across. 0 or 1 means one even comb, and an even comb is the single thing that most makes a set look machine-made. This is the setting that was missing on bursts.
WidthHow thick a line is at its heaviest point.
AccentsThe first number is what share of the lines are drawn heavy — 0.15 is about one in seven. The second is the heaviest they get, as a multiple of Width; each accent picks its own between 1.5× and that, so you get a spread of weights rather than two. A printed page always has a few fat strokes among the hairlines.
TaperHow far a line thins toward its far end. 0 is a flat bar the whole way; 1 runs out to nothing.
Entry入り — how much of the start also ramps up from a point. Together with Taper that makes a spindle: thin, thick, thin. 0 leaves a blunt cap where the stroke begins.
NeedleThe shape of the thinning. 1 is a straight wedge. Above 1 the line thins fast and then runs a long thin needle. Below 1 it keeps a belly and ends abruptly.
Hollow centreBursts only: the empty middle the art sits in, as a fraction of how far you drag.
SweepBursts only. 0 is a full circle. Anything else is a fan that many degrees wide, aimed the way you dragged — what you want when the centre of the burst is off the edge of the panel.
StartStreams only. scatter lets runs begin anywhere along the direction. from the line makes every run begin on the line you dragged from and hang off it — drips down a panel, rain, a curtain. The number beside it is how far the starts stagger off that line.
Fan toward a pointStreams only: aim every run at one point beyond the drag instead of running parallel, for a block rushing at an impact. The number is how far past the drag's end that point sits, counted in drag lengths — small is a hard perspective, large is a gentle fan.

Wobble — how much the hand varies. Every one of these is 0 to 1 (Angle is in degrees), and 0 everywhere is a drafting tool.

KnobWhat it does on the page
PositionHow far each line strays from where the even spacing would put it, as a share of the gap.
LengthHow much the lengths differ. 0 makes every line reach exactly as far as its neighbour — the clean ring, or the wall of equal streaks, that gives a generated set away.
Long biasWhich way the length wobble leans. 0 draws short and long equally often; 1 makes most lines long with a few short ones, which is how a reference page looks.
Outer lengthBursts only: the same wobble on the far end of a ray. Keep it small. A ray that stops inside the panel shows its own blunt end instead of being cut off by the border.
WidthHow much the weights differ from line to line, on top of the accents.
AngleStreams only: how far each run leans off the drag's direction. A degree or two reads as hand-ruled; 0 is dead parallel and reads as a filter.
Core staggerBursts only: how ragged the edge of the hollow centre is. 0 puts every inner end on one perfect circle, which is the compass look.
Bundle varietyHow much the bundle sizes and the holes between them vary. 0 repeats one unit at one pitch and the eye finds the period — a picket fence.
The flashes only show the knobs they use. Sea urchin and Solid flash draw filled teeth that carry their own shape, so Taper, Entry, Needle, Accents, Sweep, Bundle and most of the wobbles are not offered on them — you get Spikes, Spike width, Hollow centre, the Position and Length wobbles and Core stagger. A row that cannot change anything is worse than no row.
Shift means two different things in the Direct draw group. On the straight line it snaps the drag to 45° steps, the way you rule a horizon. On the rectangle and the ellipse it does what Clip Studio's does instead — holds the two sides equal, so you get a true square or a true circle no matter which way the drag leans. One rule used to serve both, and it was the line's: holding Shift for a circle and dragging a wide, shallow box snapped the box's diagonal to the nearest 45°, which for anything flatter than 22° is 0° — and the circle inked as a flat bar.
A figure is one weight from end to end, and one Ctrl+Z. Figures ink with the brush you are holding, but not with its entry taper: a panel border that faded in at one corner is a defect, not a flourish. And a shape drawn with Fill with drawing colour on is a single history step — the first undo used to leave the hollow outline behind.
Regenerating effect lines replaces the layer's pixels wholesale, including anything painted on top of them. Layer ▸ Edit effect lines ▸ Apply re-runs the generator with the dialog's values and the old raster is gone. It is one undo step now — if you learned to avoid the button, you can stop: Ctrl+Z brings the previous lines back. It was not undoable at all before: the regen swapped the layer's tiles wholesale, behind the recording that makes undo work, and had to purge the layer's history to stay consistent.
Only a generated layer regenerates. This is the in-place door; pointing it at an ink layer would eat the drawing, so a layer that was not generated is refused with a note in the status bar (Layer ▸ Generate effect lines makes a new one). The generator parameters are remembered per layer and only update when a regeneration succeeds.
They are live objects — press O. With the Object tool, clicking the lines' ink selects the generator and its blue driver handles appear: drag the centre to move the focal point, the ring handles to change the inner/outer reach. No dialog needed for the moves you make most. An outline on the lines is one checkbox away (Layer Property ▸ Border effect), and a generator living inside a frame folder clips to the panel like everything else.

Multi-select objects (Add / Remove / Toggle)

The Object tool’s Select setting combines clicks four ways. New replaces the selection on every click (the historic behaviour, and always what Shift-click overrides to Add). Add stacks every clicked object into a multi selection — outlined in the accent colour — Remove drops the clicked one back out, and Toggle flips membership. Del removes the whole set in one undo, texts and balloons alike.
