Drawing & selections

Stroke correction

Post correction makes the ink trail the pen. It smooths each point against the points on BOTH sides of it, so a point cannot be drawn until the pen is far enough past it — about 32 canvas pixels of stroke at 100%, less at lower settings. The line catches up the moment you lift. Stabilize is the alternative that has no look-ahead; it lags too, and it also swallows slow movement entirely. Neither is free: one costs look-ahead, the other costs a dead zone.
An Out taper holds back the end of the stroke until you lift the pen. The last Out pixels cannot be thinned before the program knows where the stroke ends, so that much ink appears on release. Set Start/end to Fade instead if that bothers you — Fade runs from the start of the stroke and holds nothing back.
By scale reads the zoom once, when the stroke starts. Zooming or rotating mid-stroke does not resize the correction under a line that is already being drawn. Same rule as the mouse smoothing floor.
Fade ignores the In length. In Fade mode the whole stroke ramps from full down to the minimum over the Out length and then holds there, so an entry taper would have nothing to do; the In slider is hidden rather than silently ignored.
Sharp angles does nothing on its own. It is an exception to post correction, so it only has an effect while Post correct is above zero. A corner sharper than about 60° is emitted exactly as drawn and the smoothing stops on either side of it.
Correction ▸ In and Sub Tool Detail ▸ In taper stack. They are two separate entry tapers — the sub tool's own (seeded from the brush the preset was converted from) and yours — and both multiply the pressure. A preset that already tapers in, like Real G-Pen, is already ramping before you add anything here.

The eraser end of the pen

Flipping the stylus over selects the Eraser tool, and flipping back restores the tool you were using. Because it is a real tool switch rather than a temporary mode, the eraser end keeps its own brush and its own size — flip back and forth and each end stays as you left it. Three deliberate limits: a flip is ignored while a line is being drawn, so a mis-reported flag can never change the tool under your hand; if you pick a different tool by hand while the pen is inverted, flipping back leaves your choice alone; and moving a real mouse cancels it. Some tablets only report the tail while it is touching, not while it hovers — if yours does, the toolbar changes as you make contact rather than as you flip.

Leaving the window mid-stroke

Alt-Tabbing away, or another program stealing the window, ends the stroke in progress — the ink you had already laid down stays and is one undo step. The keyboard and pen events that would normally finish the gesture go to the other window, so holding them open would be worse: a held Space released in the other program used to leave the canvas stuck in pan mode, where every pen press dragged the page instead of drawing. Coming back, everything is released: no held space, no half-finished stroke, no live brush-size drag. The status bar says input released when there was something to release.

Wash mode

One wash stroke can never exceed its opacity, however much it overlaps itself. In wash mode the dabs accumulate inside a stroke buffer and the whole stroke commits once at the Opacity you set — going over the same line twice inside ONE stroke does not darken it. Build-up mode (wash off) is the stock behaviour: every dab paints, and overlaps add up. Flow is the per-dab alpha inside the stroke; Opacity is the stroke.
The Ink blend box only appears in wash mode, and it is not saved with the brush. It offers the same twenty-seven modes the Layers palette does, and it decides how the finished stroke combines with what is already on that layer. Build-up strokes have no such control. The choice lives with the tool for the session — brush preset files on disk can only carry Normal, Multiply and Screen, so a stroke blend you set here is gone next launch.

Brush size

Size is an absolute dab diameter in canvas pixels, and [/] walk a ladder the Size slider can also reach. The rungs are round numbers with widening gaps — ] on 1 px gives 2, on 100 gives 120, on 120 gives 150 — from a 1 px floor to a 2000 px top rung, and a value between rungs steps past itself rather than back onto itself. There is no hidden ceiling: a 10 px brush walks all the way up. Size used to be a 0.25–4× multiplier on whatever the preset shipped at, so the ladder silently stopped four times past it and a 10 px brush could never be pressed above 40.
Each sub tool keeps its own size across restarts — but only if you moved it. A size you changed is written into ui.txt (sub_tool_size_px=) against the preset's path, so re-installing or moving the app keeps it. A sub tool you never re-sized has no entry at all and goes on taking its size from the preset, which is what lets an updated preset move it: the preset's size is the default, never a ceiling.
“Reset to preset” hands back the preset's own size AND forgets the override. The stored entry is deleted rather than overwritten with the default, so "back to the preset" that only lasted until the next launch cannot happen. See the padlock below for the other half: a locked sub tool never writes the nudge you took for one panel, so what the next launch restores is the snapshot the padlock froze.

Vector layers

A vector layer is a normal raster layer that also REMEMBERS every stroke as editable geometry. Layer ▸ New vector layer starts one; drawing feels identical — the record rides beside the pixels. With the Object tool on that layer, click a stroke: drag a square handle to bend it locally (about one brush-width of neighbourhood moves), drag anywhere else on the line to slide the whole stroke, press Del to remove it. The line follows your cursor live; the ink re-renders the moment you let go — through the same brush, pressure and stabilizer it was drawn with.
The eraser on a vector layer has three settings — Tool property ▸ Vector eraser. Touched, the default, takes only the part of the line you rubbed: a rub through the middle leaves two lines. To intersection widens the rub out to where that line crosses another line on the layer (a line crossing itself counts), or to the line's ends if it crosses nothing — the overshoot cleaner: hatch past the border, sweep the eraser along the spill, and every tail snaps back to the border line. Whole line takes any line you touch, entirely. Crossings are read on the layer you are on only. A raster layer always erases what you touched, whatever the setting says, and an eraser pass that touches no line changes nothing and spends no undo step.
Two things do not record yet, and say so. Strokes drawn with mirror or wrap-around active still ink normally but are not remembered as geometry (an edit re-render would drop their mirrored halves — so they are left out of the record instead). And editing re-renders ONLY what the layer remembers: ink that got onto a vector layer any other way (paste, fill) disappears at the first edit. Keep pasted material on ordinary layers.

Importing brushes (.abr, .sut, .kpp, .gbr, .gih)

Imported brushes land in the group imported, and a set imported twice is suffixed rather than overwritten. File ▸ Import Brushes reads Photoshop .abr, Clip Studio sub tools exported as .sut, Krita .kpp (dynamics; Krita keeps the tip in a separate resource) and GIMP .gbr/.gih: each tip becomes a grayscale texture the Tool Property texture picker lists, each brush a preset in imported/. Import a set whose name is already taken and it arrives as <set>-2 — so the copy you spent an evening retuning is still exactly where you left it, and the new import sits beside it.
Dynamics are translated as far as they honestly map. Spacing, size by pen pressure (with its minimum), size jitter, opacity and flow by pressure, opacity jitter, scatter and dab count all become real engine settings; a tip's static geometry — flip X/Y, angle, roundness — is baked into the texture bitmap, which for a static value is exact rather than approximate. Photoshop's computed (parametric round) brushes, which used to be dropped, come in as presets with their hardness, roundness and angle.
A sampled tip IS the dab's shape. An imported stamp brush lays its tip image down as the dab's coverage — corners and all, rotating with the stroke when the file asks for it — rather than texturing a round dab. And a set authored at a huge size (some Painter sets save kilo-pixel tips) imports with its default size capped at 300 px; the authored size is noted in the preset's description, and the Size control still goes anywhere.
What could NOT be translated is written into the preset's description, after “Not translated:”. Fade, tilt and direction controllers, per-dab angle jitter (stamps rotate with the stroke's direction, but random per-dab angle has no equivalent), wet edges, airbrush build-up, dual brush, colour dynamics and pattern texture have no equivalent here. Rather than drawing differently and saying nothing, each one is named in the description of the preset it belongs to. The same convention the Clip Studio import uses — a brush that lies about what it kept is worse than a brush that lists what it lost.

Make a brush from your own marks

Lasso marks on the canvas, then Edit ▸ Register selection as brush tip. The selection's ink on the active layer becomes a stamp brush in the sub tool list's Mine group, selected immediately so the test stroke shows it — the marks repeat along the stroke, clearly separated by default. Tune size and spacing in Tool Property like any other brush. A feathered (blurred) selection fades the tip's edge.
Transparent layer: the tip is the ink's opacity. Opaque artwork: the tip is its darkness. Marks drawn on a transparent layer register by their alpha. If the selected area is effectively fully opaque — ink on a white flat — alpha would be a solid rectangle, so the darkness becomes the tip instead: the black stroke, not the paper. Both readings match what the marks look like; a solid square brush from a white background would match what the bytes look like.
Right-click a brush in Mine or Imported to rename, duplicate or delete it — the shipped groups are read-only. Rename is the box at the top of that menu (Enter applies, Esc drops it), Duplicate leaves a numbered copy beside the original to retune, Delete removes the preset file and has no undo. Renaming edits the name inside the file and never the file itself, so the size you set on that brush still comes back. Right-clicking a CSP, Krita or Classic brush does nothing: those come back with the next build, so a rename there would not stick and a delete would not come back at all.
Registering a material from a selection needs no special command. The Materials palette's register-layer button is already selection-scoped: with a selection up it registers just that part of the layer.

The Tone tool and the fill's auto mode

One click tones an enclosed region. The Tone tool floods the area you click — same tolerance, gap closing and reference rules as the bucket — and lays a LIVE tone layer over exactly that region: parameters, not pixels, still editable later, one undo press for the whole gesture. No selection survives the click (removing the deselect step is the point); a selection you already had still clips. Each click makes its own tone layer.
"Auto gap & fringe" measures your line art — and says when it can't. With the fill's auto box ticked, every click first measures how thick the surrounding strokes are (median of boundary samples) and derives Close gap (about one line width) and Area scaling (half a line width — any more would paint THROUGH the line) from that. The greyed rows show what it chose, the status line narrates it, and when nothing is measurable — blank paper, solid black walls — your manual numbers stand and the status says so; it never invents a value. It costs one extra region scan per click.

Materials and tiling patterns

Right-click a material cell to tag it; the one search box matches names AND tags. There is no second field and no tag: prefix syntax. Tags are comma-separated and normalised on save, and clearing them all leaves the material byte-identical to one that was never tagged. Left-click still pastes — that is why tagging is on the right-click menu.
Tags live in tags.txt beside the images and are keyed by FILE NAME, so renaming a material file loses its tags. The same trade the use counters make (those key on the full path, so a folder you move loses its counts). What the sidecar buys is worth it: copy a material folder to another machine and the tags travel with the images, and a folder the bank has never seen is already tagged the first time you add it. A rewrite keeps lines it does not understand, and keeps entries naming files that are not in the folder right now — so a rescan, or a drive that was not mounted, does not eat them.
Some materials place LIVE, not as pixels. The bank holds two kinds of thing. A bitmap material (a tone, a texture, a scan) pastes as the move/scale float you already know. A generator material — the shipped focus-lines and speed-lines, marked (live) on the cell — places an effect-line layer that keeps its parameters: the Object tool grabs its focus point, radii, angle and density afterwards, and Layer ▸ Edit effect lines re-runs it. It is a .gen.json file in the folder, with a same-stem PNG beside it as the picture on the cell. Focus lines converge where you clicked; everything else comes from the material, because a material is reusable and a position is not. Registering a generated layer writes that .gen.json too, so a set of lines you tuned once comes back out of the bank still editable instead of flattened.
A folder import carries the tags of the files it copied, and only those. A file the copy skipped because its name was already taken contributes nothing, and whatever the destination already said about that name stands. If none of the copied files were tagged, no sidecar is created — “no tags.txt” stays the honest resting state for an untagged folder.
File ▸ New Tiling Pattern opens a square canvas in a NEW tab with wrap on both axes. A dab that crosses an edge continues on the opposite side, so the tile is seamless by construction rather than by touching up afterwards, and the Pattern Studio window shows the canvas repeated 2×2 or 3×3, re-rendered live as you draw. Mirror (symmetry) painting drops when the pattern canvas opens: wrap and mirror share the same axis slot.
Turn wrap off mid-draw and the tile seams. The preview goes on repeating whatever is on the canvas, seam and all, so the studio says wrap is off — strokes will seam at the edges in the warning colour with a one-click way back, rather than letting the preview quietly lie.
An empty tile refuses to save. Save as material composites the whole document on a transparent background at full resolution and registers it in the material bank — never trimmed to the ink, because the canvas rectangle IS the repeat and trimming it would change the tile. A canvas with nothing on it is a mistake rather than a material, so nothing is written and no file appears. The name is slugged (spaces and punctuation become underscores) and saving twice under one name suffixes — dots-2 — like every other registered material. It lands in your own materials folder, or in a materials-mine beside the exe if you have not added one.

Reference images

The References palette (Workspace ▸ References) is a list: Add images… picks photos or scans, and each row is a thumbnail you click to open that image in its own floating window. Open as many as you like — they are free windows, so three references can sit over the canvas at once, wherever you drag them. Inside a viewer: drag pans, the wheel zooms around the cursor, −/＋ step the zoom, Fit goes back to fit-to-window, and Alt+click (or the ◉ toggle, then a plain click) takes the colour under the cursor into your drawing colour — the same pick the canvas eyedropper makes, so it joins the Recent strip and obeys the auto-register switch too.

The list is remembered, the windows are not. Your reference board is still there next launch; the viewers you had open are not, because windows that reopen themselves over the canvas every morning are a nuisance rather than a feature. Click a row and it is back. The list lives in ui.txt as one escaped line, so a path with a comma or a quote in it survives.
A renamed or moved file stays in the list as a missing placeholder — it does not vanish. The row goes amber with a crossed-out thumbnail and the tooltip names the path it was looking for, so you can find what moved (or unplug-and-replug the drive) instead of wondering which reference you have lost. ✕ forgets a row when you mean it.
Big references are downscaled, once. A viewer's texture caps at 4096 px on the long edge and the decoded image is dropped the moment it is uploaded, so a folder of 6000 px photos does not eat the memory the brush engine needs. Colour picks come from a small copy taken with nearest-neighbour sampling, so a picked colour is a real pixel of the file and never a blend of two. Images load one per frame: a board of forty references trickles in rather than freezing the moment you open the palette.

Locking a sub tool

The padlock beside the wrench in Tool Property pins the sub tool you are on — for the pen you spent an afternoon calibrating and would rather not have to calibrate again at three in the morning.

A locked tool still takes every change. Drop the size for one panel, pull the opacity down for one bit of shading — it all works normally. What the lock stops is the remembering: the next time you select that sub tool, the values the padlock froze come back and the status bar says settings restored. A lock that refused the change outright would be a lock you spent the day switching off.
The lock follows the sub tool, not the app. Locking your inking pen leaves the eraser, and every other brush, free. Each sub tool has its own padlock.
Unlocking keeps the values you are looking at. Whatever you drifted to becomes that sub tool's own settings on the way out — releasing the padlock does not throw the afternoon away.
Sub Tool Detail is the same tool by another door. Everything in that window edits normally while the lock is on, and comes back with everything else; the window says so at the top so the snap-back does not arrive unannounced.
“Reset to preset” releases the lock. It throws away the stored settings, and a padlock over values that no longer exist would be a lie.
Locks are forgotten on exit. Tool Property values are session memory, and so is the padlock.

Texture

Texture grain is anchored to the canvas, not the pen. A textured brush multiplies the same grain values at the same canvas positions, so overlapping strokes reinforce the same pattern instead of laying down fresh grain each pass. A deliberate deviation from Krita.

Brush feel — Interval, density, anti-alias

Interval and Anti-alias start on "As preset", which is not one of CSP's settings. Until you pick a rung, the brush draws with exactly the spacing and edge the preset file shipped — so nothing you have been using changes the day these rows appear. Picking "As preset" again puts that exact value back, not a house default.
Narrow / Normal / Wide follow the Size slider; Fixed does not. The three named intervals are fractions of the tip (5 %, 10 %, 20 % of its width), so a brush at four times the size gets four times the gap and keeps the same look. Fixed is a literal pixel distance and holds still while the brush grows — which is what you want for a dotted or beaded line and wrong for everything else. The number beside the dropdown is the real gap at the current size.
Adjust density by gap can only make a stroke lighter, never darker. It divides one stroke's opacity across however many dabs land on a pixel, so tightening the interval stops making the line blacker — that is the cure for the faint periodic banding a sketchy brush shows. It does not work the other way: widening the gap will not be compensated back up, so a too-pale wide-gap brush needs Opacity, not this. Off is raw build-up: every dab paints at full strength and overlaps add up.
Anti-alias is a minimum, so raising it does nothing to an already-soft brush. The four levels set the narrowest edge fade the dab is allowed — a tip softer than that keeps its own edge untouched, and only a harder one is softened up to it. When it does soften, the dab is grown to match, so the line does not get thinner. "None" means genuinely aliased: a hard tip stays hard-edged, which is a deliberate choice for manga lineart, not a missing feature.
Hard dab overrides Anti-alias completely. Hard dab draws its own exact disc with a one-pixel edge and never reads hardness, so the four levels change nothing you can see while it is on — the row says so instead of showing a pixel figure that is not being used.

Color mixing, jitter, tip flip, dot pen

Mixing: Standard blends like light, Paint blends like paint. Standard adds colours the way a screen does, which is why mixing two strong colours drifts toward grey. Paint mixes them subtractively, the way pigment does — blue over yellow makes green, and a blend keeps its colour instead of dulling. It also changes the colour a smudge picks up off the canvas, and it steers Color jitter. Paint is drawn on the processor rather than the graphics card (there is no pigment model in the GPU brush path), so a very large brush can feel heavier in this mode — that is the switch, not the app slowing down.
Stretch and Blur only appear once Paint is below 100 %. Paint (CSP's "density of paint") is how much of YOUR colour a dab lays down against how much it picks up off the canvas, and at 100 % — where every pen ships — nothing is picked up, so there is nothing for the other two to stretch or blur. They appear when there is. Blur is a multiple of the brush radius, so it follows the Size slider; tick "Blur pinned to px" and it becomes a canvas distance that does not.
Color jitter's "Along stroke" varies per input sample, not per dab. The dab colour is decided inside libmypaint's own stroke loop, which we do not patch, so the finest we can move it is once per pen event — roughly a hundred times a second. It reads as grain along the stroke, which is the point; it is not literally per dab. The draw is seeded per stroke, so the same stroke always paints the same colours — an undo and redo cannot repaint a different brush.
Tip flip needs a tip texture; on a plain round dab it does nothing. The row mirrors the tip IMAGE, and a round dab is its own mirror. The row says so under itself when a mode is on with no texture picked. "On reverse" is the one worth knowing: an asymmetric tip drawn right-to-left comes out backwards, and that mode flips it per dab so both directions read the same.
The Dot Pen ignores both Size and pressure. It paints one whole pixel per dab with no soft edge — that is the definition, not a limitation, and it is why fine hatching and pixel cleanup work with it. A "1 px" ordinary brush is really a two-pixel grey ribbon whose darkness shifts along its length. It is a procedural sub tool, so the Tool Property rows that belong to the MyPaint engine do not reach it.

Fill

Area scaling is signed, and negative never pulls back from the page edge. Positive grows the fill under the lineart (overfill); negative erodes it so the fill stops short of the line (underfill). The erosion measures distance to a real boundary, and the canvas border is not one — an area that runs off the page keeps its pixels right up to the page edge however far you pull the slider negative. Same rule the selection's Shrink follows, so the two agree.
Refer to image border leaves the outermost pixel row unpainted. The switch makes the page's perimeter count as a drawn line — and you do not paint over a line, so at Area scaling 0 a one-pixel ring stays empty. The default +1 covers it again. What the switch is for is lineart that stops a few pixels shy of the page edge: on its own that slot lets a fill out over the top, and with the perimeter drawn in, Close gap seals it.
Enclose and fill needs open space at the page edge to know what "inside" means. It fills every closed area your loop encloses by flooding from the four page corners first and throwing that away — so on a page whose lineart runs right to the edge on all sides there is nothing to throw away, and the drag fills the background too. Leave a margin, or reach for the plain bucket. The selection tool's Shrink (flats) mode is the same geometry and has the same edge case.
Lasso fill ignores every fill setting. Pick that sub tool and Tolerance, Close gap, Area scaling and the Refer rows disappear from Tool Property: it paints the shape you drew, straight over any lineart inside it, so none of them have anything to describe. An active selection still clips it, like every fill.

Colour

The HEX field reverts anything it cannot read exactly. It takes #rrggbb, rrggbb and the 3-digit short form (#f80 is #ff8800). Type something that is not one of those — a half-typed value, a #rrggbbaa with an alpha on the end — and pressing Enter puts the current colour back rather than jumping to a nearby one. A guess in a colour field is worse than doing nothing: you would not notice it was a guess.
The Recent strip fills when you settle on a colour, not while you drag. Sweeping the hue ring feeds the canvas live but leaves nothing behind; the value you release on is the one that lands in the strip. It keeps the last ten, newest first, drops repeats, and survives a restart. Right-click any of them for Add all to Color Set (a copy — the strip is left alone) or Clear recent colours. Otherwise one two-second drag would fill all ten slots with the same hue.
The Color Set never grows on its own unless you tick Add picked colours. The switch is at the bottom of the Color Set palette and is off to begin with: with it on, every colour you take with the eyedropper is added (repeats ignored, and it stops at 256). The Recent strip already remembers your picks and forgets them again, which is what you want for most of them — the Color Set is the half you curate.
An imported .gpl keeps its colour names — hover a swatch to read one. Palettes downloaded for GIMP or Krita usually name their swatches ("skin — shadow"), and those names are now stored with the colour in swatches.txt, after the hex on the same line. An unnamed swatch shows its hex instead. A build older than this one reads that file too, but drops the names; it will not choke on them.

Eyedropper

The average is an average of light, not of numbers. Set Average color to 2 × 2 over a spot that is half ink and half paper and the pick comes back #BCBCBC, not the mid grey #808080 you would get by averaging the bytes. That is the honest answer: half the light really does look like that, and it is the same rule the canvas uses when you zoom out — so an averaged pick agrees with the zoomed-out page instead of contradicting it. 1 × 1 is the default and takes the pixel verbatim, exactly as it always did.
Reference layers are picked even when their eye is off. With the sub tool on Pick from reference layers the sample comes from the reference set alone, hidden or not — the same rule the fill tool follows, so you can keep roughs invisible and still pick off them. If no layer is marked as reference the pick falls back to what you see and the status line says so.
The picker ring only appears for the Eyedropper tool. Alt+click from a brush picks with the same Reference and Average settings, but draws no ring — the brush ring is already there and two rings fight. Turn the ring off in Tool Property ▸ Show color picker circle.

Gradients

The colour bar only authors what is BETWEEN the two ends. The ramp's start and end colours come from the sub tool you picked (Main → Sub, Main → Transparent, Transparent → Main), so they are not draggable and cannot be moved inwards. Click the bar to add an interior stop, drag a stop down out of the bar to delete it. Six interior stops is the maximum. On a gradient LAYER the two ends are editable too — they are that layer's own parameters, not the tool's.
Freeform is drawn lines, and needs no anti-aliasing switch. Pick Gradient ▸ Freeform and draw two lines: the first takes your main colour, the second your sub colour, and the ramp between them follows both shapes. Press Enter — or click once away from the lines — to paint it. Nothing is painted before that, so Esc (or switching tools) throws the whole thing away with nothing to undo — and the finished gradient is one undo press. Clip Studio's version of this reads lines that are already pixels on a layer, which is why it makes you draw them with anti-aliasing turned OFF or it refuses to fill. Here the lines are the gesture, never pixels, so there is no setting to get wrong and the result is smooth by construction.
A THIRD line and up carries its own colour. Before pressing Enter, just draw another line: it takes your main colour as it stands at that moment, so the way to a four-colour field is pick, draw, pick, draw. With three or more lines there is no “from” and no “to” any more — every pixel is a blend of ALL the line colours, weighted by how near each line is, so the colour on a line is exactly that line's colour and the space between belongs to whichever lines are closest. Backspace takes the last line back one at a time. Because every line pulls on every pixel, even a far-away one, adding a line changes the whole page a little — that is the model, not a bug.
Freeform ignores Edge process and Start from centre, and always bakes. Those two describe what happens outside the length you dragged, and a freeform gradient has no outside — every pixel sits among the guides. With TWO lines everything else on the ramp (interior stops, Flip, mixing mode, mixing rate, dithering) works normally. With THREE or more the ramp's positions have nothing to describe, so interior stops, Flip and mixing rate are ignored as well; the mixing mode, brightness and dithering still apply. “Create live layer” is also ignored: a live gradient layer stores two endpoints, and there is nowhere in it to keep drawn lines, so Freeform paints pixels and says so in the status bar. Beyond the two lines the colour eases back toward the middle of the ramp rather than holding flat — make a selection first if that reaches somewhere you care about. A full B4 page takes a few seconds; the straight-line gradient takes about half that on the same page.
Edge process “Do not draw” leaves the outside alone — it does not erase it. Everything past the length you dragged keeps whatever was already on the layer. The default, “Do not repeat”, holds the end colour out to the canvas edge instead; Repeat tiles the ramp and Reverse ping-pongs it.
Flip and Start from centre change the DRAG, not the bar. The colour bar always shows the ramp as authored, left to right. Flip paints it end-first and Start from centre makes the point you press the middle of the ramp rather than one end — neither redraws the bar, so the canvas is where you see them.
Dithering only touches the inside of the ramp. It is an ordered pattern worth about one 8-bit level, there to stop a long smooth ramp printing as visible bands. Where the ramp has run out and the end colour is being held flat, no noise is added — a fade to transparent leaves genuinely clean paper.
“Create live layer” retargets a live GRADIENT layer, and nothing else. With the switch on, dragging the Gradient tool while a live gradient layer is active re-aims that ramp instead of stacking a new layer — that is how you fix the angle a day later. Stand on anything else, including a tone or fill layer, and you get a new gradient layer above it and a status line saying so. A tone you spent time tuning is not something a drag should overwrite; CSP never converts the layer you are standing on either.
Brightness only exists in Perceptual mixing. The slider disappears in the other modes rather than sitting there dead. It lifts the middle of a ramp between two saturated colours back toward the brighter end’s lightness; it can never move either end, whatever the level. Standard mixes the sRGB numbers (what every paint program calls normal), Linear mixes the light itself, so a black → white ramp reads much brighter halfway across in Linear than in Standard.
Applying a saved gradient REWRITES your main and sub colours. A saved gradient owns its two end colours, but the tool takes its ends from the palette — so Apply sets main (and sub, and the sub tool mode) to whatever reproduces the saved ramp. Apply it while standing on a gradient LAYER instead and nothing in the palette moves: the layer holds its own ends.
Import reads GIMP .ggr, not CSP .cgs or Photoshop .grd. Those two are undocumented binary formats; .ggr is plain text and most gradient packs are published in it as well. A .ggr with more than six interior boundaries keeps the first six and still lands both ends, rather than refusing to load.
The gradient set lives beside the exe, not in the document. It is one line in ui.txt, so it follows the install and not the file you are drawing. Every list button saves it immediately — there is no separate Save.

Selections

Selections are not in the undo history. Deselecting, growing, inverting — none of it has an undo step. CSP parity, deliberate. What you DO inside a selection (paint, fill, transform) is undoable normally; the selection itself is session state.
Flip is bounded by the selection. Every pixel outside the selection is byte-untouched by a flip or transform commit — deliberately unlike CSP's never-fixed 2016 transform bug that destroyed neighbouring content.
The launcher can let strokes escape the selection. The pen-crossing-a-box button in the selection launcher toggles "allow drawing outside" for the current selection: with it on, brush and eraser strokes land outside the ants too — handy for patching a gap in lineart mid-way through building a multi-part selection, without throwing the parts away. It frees strokes only: Fill, Delete, gradients, filters and pastes still clamp to the selection no matter what. Every new selection (including any grow/shrink/invert/ combine) starts clamped again. The default is the safe one — the toggle exists for the thirty seconds you need it, and a rebuilt selection forgetting it means a stray stroke can never contaminate work you did an hour later.
Reset is not the same as Esc. The Reset button in Tool Property puts the float back to the size, angle and position it was lifted at and stays in the transform; Esc leaves the transform altogether and takes the lifted selection with it. Reset leaves the reference point where you put it — it is a setting, not part of the transformation.
Moving the transform reference point shifts the content. The pivot is not cosmetic: moving it re-derives the transform from the same scale/rotation values around the new pivot, so the preview moves. The honest recomputation, not a pinned preview.
Interpolation only matters when you SHRINK, and "High accuracy" is the one for lineart. Smooth edges (the default, bilinear) reads two pixels per step, so below about half size a 1 px line can fall between the samples and vanish outright — not faint, gone, and the line reads as broken. High accuracy averages the whole area each output pixel covers, so hairlines come through grey instead of missing. On a test page of twenty 1 px lines shrunk to 35 %, Smooth edges kept twelve and High accuracy kept all twenty. Hard edges invents no new colours at all (pixel art, 1-bit pages); Clear edges sharpens an enlargement. The row is greyed out during a mesh warp, which resamples through its own lattice instead.
The magnetic lasso only re-aims while the pen is down. Press and drag and the outline snaps to the lineart as you go. Lift the pen and the line to the cursor goes straight and stays straight — that is not the path the next drag will take, it is just telling you where the trace left off. Press again and it snaps from there. The snapped wire is a shortest-path search, and running one per mouse-move with the pen up would cost you a search per frame for a preview you did not ask for.
Lifting the pen plants an anchor, and only Enter, Esc or a click on the ringed first point ends the trace. The lift is not the end of the gesture — the outline stays open so you can trace a long edge in several comfortable strokes. Backspace takes anchors back one at a time and cancels the whole trace at the first one.
Drag too far without an anchor and the magnetic lasso stops snapping. Past roughly 500 px between anchors the search window would be big enough to stall the page, so the wire gives up and runs dead straight. It plants anchors itself every ~48 px while you drag, so you only see this by dragging with the pen up. A straight segment where you expected a snap means "drop an anchor".
Snap range is the whole of the magnetic lasso's tuning, and it cuts both ways. Tool Property ▸ Snap range (default 40 px) is how far off your cursor the wire may wander to find an edge. Too small and it ignores the line you are tracing; too large and it can prefer a stronger edge you did not mean — the next panel border rather than the chin. It also bounds the search, so a large range is slower.
The magnetic lasso snaps to the page as you see it, not to the layer you are on. Every visible layer feeds the edge detector, so it will happily follow a line drawn on a layer you are not editing. Draft layers and hidden layers are the two exceptions — it ignores both, the same rule fill and the magic wand follow. Snapping to the rough underdrawing instead of the finished line is the one wrong answer that would be worth reporting as a bug.
A blurred (feathered) selection moves softly. Blur a selection in the selection launcher, then transform: each pixel travels by its coverage fraction, so the edge fades instead of cutting at a hard line. Paint and fill read the same feather — the edge is a gradient, not a step.

Pasting into a selection

Every paste lands on its own new layer. Ctrl+V no longer opens the move float under the pen: the pasted art commits immediately as a fresh Pasted layer (inside the frame folder when you paste into a panel), aimed and sized exactly as before. To move, scale or rotate it afterwards, press Ctrl+T — or just grab it with the Object tool.
With a selection up, the paste arrives masked to it. Paste while ants are on screen and the ants become the pasted layer's layer mask — not destructive: remove or disable the mask and the whole paste is there. A feathered selection blends the edge rather than cutting it, the same coverage the brush and the fill read. The mask is taken from the selection as it stands at the paste itself; deselect first (Ctrl+D) if you want the paste unmasked. The status line says "masked" when it happened, so a paste that vanished into a small selection tells you why.

Liquify

The Liquify tool warps the layer directly, as you drag. Not a filter, not a transform float: push moves ink with the pen, expand and pinch bulge and scrunch (hold the pen still and they keep working), push left/right shifts ink perpendicular to your stroke, and the two twirls rotate about the cursor. Alt inverts any mode — expand becomes pinch, push reverses, twirl turns the other way.
One gesture, one undo. However long you drag and however many modes' worth of smearing that took, the whole drag is a single Ctrl+Z. Strength also sets the hold speed for the accumulating modes, and the falloff is soft: material piles up ahead of the brush and feathers out behind it, exactly like a fingertip pushing wet ink.

Mesh transform

Edit ▸ Transform ▸ Mesh Transform bends the layer through a lattice. The content lifts into a float (same rules as Ctrl+T) and a 5×5 grid of points lays over it: drag any point to bend the grid — the preview shows the deformation live, textured quad by quad — and drag BETWEEN the points to slide the whole mesh. Enter commits (the bitmap is resampled through the deformed quads), Esc puts everything back, and the whole gesture is one undo. Only raster layers.

Puppet warp

Edit ▸ Transform ▸ Puppet Warp pins the content and lets you pull it around. Click to drop a pin, drag to pull, Alt+click a pin to remove it. The lattice bends smoothly under the pins — the preview shows it live — and Enter commits through the same resample as the mesh transform. One undo per gesture, raster layers only.
A pin holds softly, not welded. The pull of one pin falls off over about a lattice cell, so a pin sitting still on the shoulder keeps its neighbourhood essentially in place — a few pixels of bleed at most — while the pulled side travels the full drag. If you need a hard anchor, drop pins tightly around what must not move.
