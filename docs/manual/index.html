MangaNakama manual

This manual documents the things you would never guess — behaviour that differs from CSP, one-shot confirmations, modes that arm and disarm, actions that are not undoable. It is not a feature tour: a feature tour is what every abandoned help file is. If something surprised you, it should be on one of these eight pages.

The five that bite in the first hour

Clicking a layer's mask square arms mask editing. Your brush now writes to the mask, not the layer — the square you clicked is the mode. Click it again (or a layer's thumbnail) to go back. Layers & masks
Mask strokes are not undoable. There is no undo step that restores a mask stroke; re-paint the change instead. Layers & masks
Deleting a frame folder's last frame takes a second press. The first Delete arms (the status line says so); any other command disarms; the second removes the folder with its layers. This is the only thing standing between Delete and a vanished panel. Comic
Press the Object tool's key again to move through the stack. With something selected in the Object tool, O cycles everything under your click — text, then the balloon, then the frame — and Shift+O goes back. The status bar names each hop. Text & objects
Ctrl+D is Deselect. CSP uses it for Reselect; we kept Deselect deliberately. Reselect lives on Ctrl+Shift+D. Keys
