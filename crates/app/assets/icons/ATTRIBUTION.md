# Icon attribution

`lucide/*.svg` are from [Lucide](https://lucide.dev) (ISC licence, Lucide Contributors; the
original Feather icons are MIT, Cole Bemis). The SVG path data is parsed at runtime by
`crates/app/src/ui/icons/svg.rs` and painted as egui strokes, so the glyphs stay crisp at any DPI
and take the theme colours. Copied 2026-09-05 from the shared library in `Magic Writer/iconlib`.
